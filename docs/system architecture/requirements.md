# Bước 4 — Yêu cầu thiết kế kiến trúc hệ thống

| Mục | Nội dung |
|---|---|
| Việc cần làm | Thiết kế trước khi code để tiết kiệm hàng tuần refactor sau này. |
| Tech stack | Chọn framework, database, AI services phù hợp bài toán, không chỉ chọn cái mình quen nhất. |
| System architecture | Thiết kế luồng `frontend ↔ backend ↔ AI pipeline ↔ database` và vẽ diagram. |
| Database schema | Thiết kế tables/collections trước khi viết model. |
| Auth flow | Đăng nhập, phân quyền roles, thiết kế sớm và implement sớm. |
| Output | Architecture diagram + DB schema + API spec đơn giản, không cần formal. |
